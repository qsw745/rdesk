# 官方服务器配置收口

用户已授权按安全评估整改，并说明自定义地址原本用于将来迁移服务器。普通版固定使用官方 HTTPS 域名；同域名迁机通过 DNS、证书和数据迁移完成，无需修改客户端。更换域名由维护者修改 `AppConstants`、本地验证后发布客户端。不引入可被普通配置文件改写的服务地址，也不新增远程配置服务。

## 方案取舍

- 仅隐藏编辑入口：旧偏好仍可能影响请求，不满足整改目标。
- 官方集中配置（采用）：移除网络页与地址写入接口，所有官方请求使用受控 HTTPS 地址，保留现有局域网直连。
- 高级自建服务器模式：需要服务器身份验证、完整账号隔离和独立交付，当前不开放。

## 安全与兼容

首次使用官方配置前，先迁移旧存储。已知历史官方地址可保留账号；自定义地址或已记录的官方来源发生变化时，清除账号令牌、自动续登、指纹/面容凭据及可信设备，要求重新登录。迁移完成标记最后写入，失败不得继续发送网络请求。账号会话和安全存储中的登录凭据绑定官方来源，防止将来更换域名时跨来源重用。界面不展示可编辑服务器；旧网络页深链回落常规页。局域网直连仍可使用现有 HTTP 协议，不把官方请求限制错误套到本地设备。

## 验收

真实请求测试证明任意旧地址均不会成为目标；旧官方登录兼容、自定义来源清理、自动续登与生物识别隔离、被控端上传均有回归覆盖。执行 Flutter 分析、完整测试、本地 iOS 构建与真机安装启动；检查无云构建触发后提交并推送 master。仅本地安装，不发布商店或官网。
