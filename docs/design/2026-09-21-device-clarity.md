# 设备直连与可读性优化

用户要求：同账号在线设备直接连接，提升全部/在线筛选文字对比度，说明为什么开机需要家中助手。

- 设备卡片直接执行已有的服务端账号授权和连接，成功进入远控；不再跳远程协助预填 ID。访问密码仅在非账号设备或失败重试时呈现，原有跨服务器来源隔离保留。
- 连接弹窗显示进度、取消、实际错误与重试；取消、退出账号、切换服务器后的迟到会话必须断开，不打开远控。同账号身份来自当前服务器的账号设备快照，不能由收藏/历史推导。
- Windows 当前仅控制其他设备和配置开机；在线不代表支持被远控。卡片明确能力，不提供无效连接按钮；本机不提供自连接。
- 全局筛选 chip 使用不透明底色、明确的选中/未选中文字颜色，浅深主题均验证实际渲染文字对比度 >= 4.5；窄屏和放大字体允许换行。
- WOL 原理不限定 Android。UU 的开发者 App Store 介绍明确支持路由器辅助设备。RDesk 当前只实现 Android 助手，不冒称支持小米 AX3000，不复用其他产品私有协议。助手与电脑只需同一家庭网络，不需要紧挨电脑。iPhone/电脑可作为在外控制端。
- 本轮不改 API、路由器固件或账号授权协议；物理 WOL 和隔夜稳定性需要真实硬件验收。
