# 局域网开机助手与诊断

## 目标和取舍

用户希望外出可以稳定开机，不依赖专门留家的安卓手机，且能自行查看失败原因。本轮实现可在有程序运行权限的 Linux 路由器、NAS、常开主机上运行的助手，复用已部署的账号和远程开机协议，不改生产 API，不改路由器固件。

首选拓扑：控制端 → HTTPS 服务 → 主动长轮询的家中助手 → 指定 LAN 网卡的子网广播 → 电脑网卡。无需公网入站端口，不依赖关机电脑的 NAT 或 ARP 缓存。现有 Android 助手继续可用。直接向家庭公网地址单播不是本轮的稳定性主路径。

UU 开发者的 App Store 介绍确认支持路由器作为辅助设备，但没有说明用户这次实际选用了哪台辅助设备或具体转发实现，不能据此断言它仅靠内网穿透。现场后台已看到 AX3000T、稳定版 2.0.28 和“插件安装”，但尚无证据证明原厂固件允许安装本程序。AX3000T 存在硬件差异，不能直接按名称选择芯片或刷机包。

## 实现

- 独立 Go 标准库程序，不引入远程构建。Linux 静态成品本地交叉构建，macOS 版本提供账号注册助手、诊断读取等管理命令。
- 账号密码只由标准输入读取用于注册/诊断；运行配置只存助手专用令牌。配置与日志目录私有，独占进程锁，原子落盘。
- 只允许 HTTPS，不跟随重定向，证书验证，响应限长，网络请求限时。不会执行服务器下发的命令或任意 URL。
- 显式绑定本地 LAN 接口、IPv4 CIDR 和接口硬件地址；每次发送重查。地址、网卡或网络发生变化时停止发送并报告，不自动切换其他网络。
- 在授权前持久化请求占位；最多三次广播，间隔 200ms，受服务器最长 2 秒授权与请求截止时间共同约束，扣除请求耗时。重启与回执丢失只重报结果，不再次广播。
- 出站连接带退避与抖动；配置/令牌错误清楚报错；systemd/procd 交由设备自身托管。不开启公网管理端口。
- 本地有界 JSONL 日志只记录事件、请求标识、错误码、发送次数；不写账号密码、令牌、原始包。账号诊断命令读取现有请求时间线，解释卡在哪一段，支持保存文本。

## 验收与边界

本地测试覆盖 TLS、重定向、响应上限、有效数据包、授权过期、网络变化、取消、重复请求、丢回执、重启及日志脱敏。真实本地服务验证现有协议兼容性。

发包回执不是物理开机证据。电脑应用心跳也不是 BIOS/供电实测；Windows 当前在用户登录后才自启动，未收到心跳不能直接判断硬件未开机。跨网、睡眠/关机、隔夜 24/48 小时仍需实机验收。

本轮不声称 AX3000T 原厂固件已安装、不刷机、不公开家庭端口、不自动重启用户电脑。安装入口验证前，发布为通用 Linux 助手与诊断工具，不替换现有手机安装包。
