# RDesk 2.2.1 应用内更新验收

## 功能与边界

- 启动/回前台自动检查（成功六小时、失败一小时节流）；设置 → 关于可手动检查，支持关闭自动检查、忽略版本、恢复提醒。
- Windows EXE、Android APK、Mac 按当前进程架构选择 DMG/ZIP；固定官网下载，流式保存并验证长度和 SHA-256；支持进度/取消/重试，安装前再次校验。
- 安卓额外验证同包名、同签名和更高 versionCode，安装来源授权由用户操作，受限 FileProvider 仅暴露更新缓存。
- 安装前明确确认可能关闭应用/中断屏幕共享，观看端会话未结束则拒绝安装。只报告打开系统安装器，不声称安装完成；Mac 仍需拖入应用程序替换。
- iPhone 只打开 App Store；公开查询仍为 2.1.0，不把本地 2.2.1+18 当作商店可用更新。本轮未上传或提交 App Store。
- 自动提醒仅发生于应用运行期间，没有 APNs/厂商后台通知。旧版需先从官网手动安装一次 2.2.1。

## 验证

- Flutter 全量 135 项通过、1 项 Windows 专属测试跳过；更新专项 17 项通过，包含 320/640/1200 宽度、2 倍字体无溢出。
- flutter analyze 无错误/警告，32 条信息级提示保留，无阻塞项。
- 独立代码审查发现并修复下载准备/完成窗口的取消失效、重启后节流导致提醒消失；复核无剩余实质性阻塞。
- 安卓本地 release 构建、APK 签名/包名/版本验证通过；签名与 2.2.0 一致。没有连接安卓设备，系统安装来源授权及真实覆盖安装未实测。
- Windows 本地 Parallels VM + VS2022 构建通过，x64 PE、启动存活、安装到临时目录并核对文件摘要通过。GUI 自动化不能可靠向 VM 发送操作，应用内点击安装器的界面交接未实测。
- iPhone 物理设备 2.2.1 (18) 已安装并启动。iPhone 镜像提示手机正在使用，未打断；商店跳转界面未实测。因 Xcode 27 的最低目标校验，本地命令覆盖部署目标为 iOS 15，源码最低系统声明仍为 13；本地包不适用于 iOS 13/14。
- Mac arm64/x64 分别本地构建通过；两种应用与 Apple 芯片 DMG 均经 Apple 公证 Accepted、staple/validate 通过；保留 /Applications/rdesk.app 原安装（含其他未提交录屏修改），没有覆盖本机原应用。
- 本任务没有改动/重启 API 服务，没有远程/云端构建。
