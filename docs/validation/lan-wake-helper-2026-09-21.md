# 局域网开机助手 0.1.0 验证

日期：2026-09-21。基于 master `416bd51`，独立工作树开发；原工作区 macOS 按需采集等 14 个未提交修改按已有 SHA256 清单核对一致。

## 已完成

- `tools/wake-helper`：Go 标准库 Linux 助手、账号登记、只读中文诊断、持久去重、轮换脱敏日志、systemd/procd 模板。复用现有 API，没有修改手机、Windows 客户端、更新清单或生产服务。
- Go 1.26.1 本地测试与交叉构建，无第三方 Go 依赖。Linux amd64/arm64/armv7 为静态 ELF，macOS arm64/amd64 为管理命令成品，约 6 MiB/文件；未据此推断运行内存。
- `go test -race` 与 `go vet` 通过。本机运行 11 个顶层测试全部通过；另在 Linux 隔离容器运行 11 个顶层测试通过，1 个需要本机 Rust 二进制的测试按条件跳过。
- 覆盖数据包、MAC 校验、拒绝重定向/超大响应、授权过期、网络变化、取消、私有文件、独占锁、中文诊断和敏感字段排除。
- 授权已消费但响应丢失：不发包、不重复授权，重启只上报不确定结果。第一包后取消并重启：不继续广播。三包后回执丢失：只重报回执。
- 真实本地服务联调：干净 master 源码本地编译 `rdesk-server`，临时数据目录、TLS 测试代理接本地服务，完成登记、长轮询、授权、三个 loopback UDP 包、回执、模拟应用心跳、诊断和重启不重发。最初本机缓存旧二进制未包含完整字段，重编当前源码后通过；未改变生产服务。
- 实际 Linux 套接字验证：本机 Docker 内部隔离网段 `172.30.248.0/24`，ARM64 静态测试程序，仅 CAP_NET_RAW，验证接口绑定、指定源地址、UDP 9 子网广播和完整 102 字节接收。没有向家庭 LAN 发包。测试网络已移除。
- 独立只读审查后修复 systemd/OpenWrt 路径、procd 恢复次数耗尽、失败回执文案三项问题。补充日志写入失败的脱敏告警。定向复核无阻塞项。

证据在 `.release-work/20260921/lan-wake-helper/evidence/`：`build.log`、`protocol-tests.log`、`linux-tests.log`。成品与 `SHA256SUMS` 在同级 `artifacts/`。普通 `go test` 跳过真实服务测试；设置 `RDESK_TEST_SERVER_BINARY` 后执行。Linux 广播测试需要 `RDESK_ISOLATED_BROADCAST_TEST=1`，只允许在隔离测试网络启用。

- AX3000T 原厂 2.0.28 的安装权限、准确硬件架构、CA、存储、运行内存与长期写入开销。本程序不是小米 `.mpk`。
- 用户 UU 实际选用的辅助设备与内部转发链路。
- systemd/procd 在真实目标设备上的安装、重启与掉线恢复。
- Windows 睡眠/关机、跨网、隔夜、24/48 小时物理 WOL。模拟心跳和发包不是物理开机证据。
