# Windows 2.3.7 发布记录（2026-10-10）

## 内容

- 源码：提交 `20a8bc0`（版本 2.3.7+30）。2.3.6 发布后第一次在实体 Windows 电脑上经公网中继连通，随即发现两个问题并在本版修复：
  - 被控端没有处理「路径拖动」指令。观看端的每次拖动都以路径发送，Windows 与 macOS 被控端都没有对应分支，拖窗口、框选文字不生效。现在 Windows 沿路径逐点拖动，macOS 暂按起止两点直线拖动。2.3.6 发布前的端到端检查只覆盖了点击、文字和按键，没有覆盖拖动。
  - 观看端把鼠标右键当作普通点击（画布只按触屏处理，按住不动约半秒才算右键）。现在鼠标右键单击直接发送右键。这项修复在控制端，Windows 2.3.7 作为控制端时生效；Mac 控制端的修复只装在开发机上，官网 Mac 仍为 2.3.5。
- 只发布 Windows。macOS 2.3.5（28）、Android 2.3.2（25）、iOS 商店 2.1.0 不变。
