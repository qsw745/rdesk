# 远程开机简化与本地发行验证（2026-09-20）

## 变更

- Windows 配置改为「检测设备 → BIOS 设置 → 开机测试」；单一在线助手自动选择，多助手明确选择，已选择的助手离线时禁止悄悄换绑。
- 首页采用电脑卡片与开机按钮，历史、换绑和移除配置收进「更多」。Android 助手保留简单开关及后台运行提示。
- 只读检测魔术包、已授权唤醒设备、驱动提供的关机唤醒选项；未知结果不能显示通过。BIOS 仍由用户手动核对。
- 有线识别兼容 `NdisPhysicalMedium=0` 且 `InterfaceType=6`，不把接口类型 71 的 Wi-Fi 误认为有线。此问题在本地 Windows 虚拟机中复现；修复前回归测试失败，修复后通过。
- 自动启动仅在保存配置时按用户选项写入当前用户的 Run 项，不创建开机前服务，不绕过 Windows 登录。

## 验证

- 干净构建副本导自 `33861b6`，加入本次功能文件；没有打入工作区其他未提交的桌面捕获与 App Review 改动。
- 干净副本 Flutter 全量测试 73 项通过；工作区此前全量 82 项通过；新增有线识别后针对性测试 9 项通过；助手离线不换绑的界面回归 3 项通过。
- Flutter 静态分析无错误和警告，仍有 28 项提示级问题。中文配置界面渲染检查通过，没有将检测未知项渲染为成功。
- 本地 Windows 11 虚拟机运行实际网卡与唤醒查询：以太网类型 6、物理介质 0；唤醒授权未开启、魔术包 Unsupported、关机唤醒未知，均没有误报已开启。
- Android 2.1.2+16 在本地构建，包名 `com.qsw.rdesk`，沿用原发布证书并通过签名检查。当前没有连接 Android 手机，未执行覆盖安装。

- Windows 在本机 Parallels Windows 11 中使用 Flutter 3.41.4、VS 2022 C++/ATL 构建，PE 为 x64，主程序版本 2.1.2+16；启动 8 秒存活、Inno 安装包生成、静默安装及主程序哈希一致性通过。
- Windows 构建脚本固定 VS 2022，避免 VS 2026 对旧插件协程开关的不兼容。依赖使用本地缓存，没有让服务器或 GitHub 托管 runner 编译。
