# 远程开机简化与本地发行验证（2026-09-20）

## 变更

- Windows 配置改为「检测设备 → BIOS 设置 → 开机测试」；单一在线助手自动选择，多助手明确选择，已选择的助手离线时禁止悄悄换绑。
- 首页采用电脑卡片与开机按钮，历史、换绑和移除配置收进「更多」。Android 助手保留简单开关及后台运行提示。
- 只读检测魔术包、已授权唤醒设备、驱动提供的关机唤醒选项；未知结果不能显示通过。BIOS 仍由用户手动核对。
- 有线识别兼容 `NdisPhysicalMedium=0` 且 `InterfaceType=6`，不把接口类型 71 的 Wi-Fi 误认为有线。此问题在本地 Windows 虚拟机中复现；修复前回归测试失败，修复后通过。
- 自动启动仅在保存配置时按用户选项写入当前用户的 Run 项，不创建开机前服务，不绕过 Windows 登录。
