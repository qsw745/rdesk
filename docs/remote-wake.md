# 远程开机：配置、排障与验收

补充实验路径（2026-09-21）：支持运行自定义程序的 Linux 路由器、NAS 或常开主机可使用[局域网助手与诊断工具](lan-wake-helper.md)，复用下述开机协议。尚未证明用户 AX3000T 原厂固件可以安装；现有 App 的主要配置引导仍按安卓助手显示。见[验证边界](validation/lan-wake-helper-2026-09-21.md)。

实现路径：手机或电脑上的 RDesk → HTTPS 账号服务 → 家中安卓前台助手 → 家庭局域网 UDP 广播 → Windows 有线网卡。无需公网 IP、端口映射或小米 AX3000 插件。此功能不提供 Windows 被控桌面。

## 首次配置

1. 安卓手机连接电脑所在家庭 Wi-Fi（不能是隔离访客网络），保持充电；登录账号，在「远程开机 → 开始配置」启用「家中开机助手」。允许通知、后台运行，并根据手机厂商设置自启动与电池不限制。通知栏可停止助手。助手不要求录屏或无障碍权限。
2. Windows 电脑网线连接 AX3000 局域网端口，登录同一账号，点「启用远程开机」，按「检测设备 → BIOS 设置 → 开机测试」完成。自动选择已连接的有线网卡、同账号唯一在线助手；多个助手需要明确选择。网卡名称和切换放在「电脑名称与网卡」中。程序只读查询网卡、电源管理和已授权唤醒设备，分别展示已开启、未开启和无法自动判断，不修改 BIOS、电源或网卡配置。物理介质为 0 时结合以太网接口类型 6 识别，不把无线接口类型 71 当作有线网卡。不能据此保证硬件唤醒成功。
3. BIOS 中按主板文档开启 Wake on LAN / PCIe 唤醒，检查 ErP 是否会切断网卡待机供电。网卡高级属性开启 Magic Packet 唤醒。先验收睡眠，再验收关机；快速启动、休眠和软关机支持取决于主板、驱动与电源状态，不能承诺所有电脑均支持。
4. 保存时可选择「登录 Windows 后自动启动 RDesk」，仅设置当前用户的 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\RDesk`，不安装开机前系统服务或跳过 Windows 登录。专用心跳每 10 秒上报，30 秒无心跳视为应用离线；未登录 Windows 或 RDesk 尚未启动时，电脑可能已经通电，但界面仍是“未确认上线”。
5. 外出的另一台手机关闭 Wi-Fi、使用移动数据进入远程开机页；留在家中的安卓助手继续保持家庭 Wi-Fi。日常只需点电脑卡片上的「开机」，记录、更换助手和移除电脑在「更多」里。仅助手在线且电脑应用离线时允许发起。

安卓切换 Wi-Fi 或网络接口发生变化后会停止，回到家庭 Wi-Fi 需手动启用。停用保留助手身份和电脑绑定，再启用会轮换凭据；删除助手后，可在手机的电脑卡片「更多 → 更换家中助手」中重新绑定。普通同一接口的互联网短暂断线会退避重连。手机重启、系统强制结束后需重新打开应用启用；前台通知和充电也不能替代厂商后台限制与实机隔夜验证。

## 状态含义

| 状态 | 证据与处理 |
| --- | --- |
| 家中助手离线 | 30 秒内未收到该助手鉴权轮询；检查手机电源、Wi-Fi、通知与后台限制 |
| 请求已提交 / 助手正在发送 | 请求持久化或被该助手领取，不代表电脑已启动 |
| 信号已发送，等待电脑上线 | 安卓完成有界广播并回执；不会据此宣称开机成功 |
| 电脑已上线 | 请求创建后收到该 Windows 目标的专用心跳，且存在发送回执 |
| 未确认上线 | 120 秒观察结束未收到符合条件的心跳；检查 Windows 应用、网卡与主板 |
| 请求已过期 / 已取消 / 服务中断 | 本次不再发送；恢复环境后由用户重新发起 |

“当天可以、隔天失败”目前没有已确认根因。广播发送避免依赖路由器长期保存离线电脑的 ARP 项，但无法解决网卡待机掉电、主板不支持某种关机状态或安卓被系统停止等问题。

## 协议与安全边界

- 账号拥有目标与助手；各角色使用独立随机令牌，设备令牌不可调用账号管理接口。服务端仅存设备令牌 SHA-256 摘要，安卓使用 Keystore 加密，Windows 使用系统安全存储。
- 请求 30 秒有效；相同目标活动请求去重，每账号每分钟最多 10 个新请求。终态后仍遵守从创建时刻起 30 秒的冷却；每账号最多 20 台目标、5 个助手。
- 领取持久化后返回；发送前再授权，许可最多 2 秒且不得越过原有效期。安卓保守扣除授权往返耗时，发送 3 次、间隔 200 ms，仅在选定 Wi-Fi 的 IPv4 子网广播 UDP 9。
- 本地先记录请求 ID，再发送；重复领取只补回执。授权之后进程崩溃或回执丢失时不自动重发，可能显示不确定/过期，避免旧请求意外开机。
- 停止助手、退出账号、切换账号/服务器使本机待发操作失效。撤销到达服务端后阻止后续授权；已经发给助手的极短有效许可无法隔网原子撤回，已发出的 UDP 包也不能撤回。
- 最近在线时间在本服务运行期间保留最多 7 天用于诊断，在线判定仍只使用最近 30 秒。服务重启将所有非终态请求标为中断并清空在线租约和最近在线时间，不回放。配置与账号在同一用户文件原子保存；账号注销成功同步删除配置与记录，写入失败不先清内存账号。
- 诊断仅存状态、时间、错误码、配置关联，最多 7 天 / 每账号 50 条；没有原始令牌或 Magic Packet 内容。安卓额外保留最多 100 个请求 ID 与执行结果用于去重，不含 MAC 或凭据。

## 上线顺序

公网服务和 `/api/wake/` HTTPS 路由已于 2026-09-20 部署，通过协议测试，见 [部署记录](validation/remote-wake-deployment-2026-09-20.md)。客户端 2.1.2 简化配置流程；iOS App Store 版本更新另行处理。使用自建旧服务器时仍可能返回“服务器暂不支持远程开机”。服务端和客户端均在本地构建、验证后上传，不使用生产机或 GitHub Actions 构建。

服务仍使用既有 `rdesk-server` systemd 与用户文件路径。升级前备份用户文件；旧二进制不了解新增 wake 字段，直接降级后写文件可能丢失开机配置，回滚应恢复匹配备份。不要在不同版本服务进程间共享写入同一用户文件。
