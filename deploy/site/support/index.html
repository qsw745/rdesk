快速开始

随控需要两台设备：一台作为被控端（被查看和操作的设备）， 另一台作为主控端（发起连接的设备）。

  1. 在被控设备（Mac、安卓或 Windows 电脑）上打开随控，进入「协助」（电脑上为「远程协助」）， 在「允许别人控制本设备」中记下本机设备码与临时验证码；电脑需打开「允许远程控制本机」
  2. 在主控设备上进入同一页面，在「远程控制其他设备」填入对方设备码
  3. 填入验证码后点「远程控制」；验证码也可以不填，由对方在被控设备上同意
  4. 两台设备登录同一账号时，会自动出现在「设备」列表中，点「连接」即可

App Store 当前的 2.1.0 版仍是旧界面，对应入口为「远程连接 → 密码连接」。

常见问题

提示「未找到在线设备」

说明被控端当前不在线。请检查：

  • 被控设备上的随控是否正在运行（不能只是装了但没打开）
  • 被控设备是否联网
  • 设备 ID 是否输入正确（9 位数字）

连接成功但画面是黑的（macOS 被控端）

macOS 需要手动授予屏幕录制权限：

打开「系统设置 → 隐私与安全性 → 屏幕录制」，找到随控并打开开关。 授权后需要重新启动随控才会生效。

如果还需要用鼠标键盘操作对方电脑，同一位置的「辅助功能」也要一并授予。

iOS 设备能被别人看到，但对方操作不了

这是 iOS 系统的限制，不是故障。iOS 上的随控可以共享屏幕画面， 但系统不允许第三方 App 接收远程触控指令。

如果需要完整的远程操控，请把 Android、macOS 或 Windows 设备作为被控端。

让 Windows 电脑被远程控制

Windows 版从 2.3.6 起可以被远程查看和控制。这项功能默认关闭：在那台电脑上打开随控， 进入「远程协助」，打开「允许远程控制本机」。之后重新启动随控会保持你的选择。

被查看或操作时，右下角通知区域会弹出提示；右键随控图标可以「断开远程查看」或「停止被远程控制」。

目前的限制：

  • 电脑锁屏或停在登录界面时无法查看和操作。远程开机后，需要已经登录 Windows 才能被控制。
  • 以管理员身份运行的窗口和系统权限确认弹窗只能看到画面，无法操作。
  • 要在设备列表里直接连接 Windows 电脑，控制端也需要是支持该功能的版本；Mac 与安卓的对应版本尚未发布。

Windows 安装包没有发布者签名。首次运行出现「Windows 已保护你的电脑」时，点「更多信息」再点「仍要运行」。

如何在外出时开启家中的 Windows 电脑

2.3.0 起只需两个开关，电脑和手机登录同一账号即可，不再需要扫码配对：

  1. 家中助手：在留在家里、长期供电联网的安卓手机或 Mac 上打开「远程开机」，开启「作为家中开机助手」。Mac 需保持唤醒并运行随控，可开启「登录 Mac 后自动打开随控」。
  2. Windows 电脑：用网线连接路由器，在「远程开机」打开「允许远程开机」。随控自动识别有线网卡和家中助手，并开启登录后自动启动；主板 BIOS 需开启网络唤醒（Wake on LAN），页面内有设置说明。
  3. 外出时：在设备列表中，关机的电脑会显示橙色「开机」按钮，点一下即可。绑定的助手离线时会自动改用其他在线助手。

“已发出开机信号”只表示家中助手完成了广播；电脑启动并运行随控后才会显示“在线”。不同主板、网卡和 Windows 电源设置差异较大，请先测试睡眠和刚关机，再测试隔夜与长时间关机。无需路由器端口映射；App Store 当前的 2.1.0 版尚不包含远程开机。

手机端的「电脑键盘」支持哪些按键

远控会话中点击底部「键盘」，或打开「操作 → 电脑键盘」即可使用。 「输入法」页可发送一段中文或英文文字；「电脑键盘」页的字母、数字、空格、 删除和回车支持 Android 与 macOS 被控端。Esc、Tab、方向键及全选、复制、 粘贴、剪切、撤销、重做目前仅支持 macOS 被控端，并且需要授予 随控 「辅助功能」权限。

安卓或无法识别远端系统时，不支持的桌面按键会直接停用，避免出现点击后无响应。

画面卡顿或延迟高

  • 优先使用局域网直连：两台设备在同一网络时， 在被控端「远程连接」页找到直连地址，主控端直接填该地址， 数据不经过服务器，延迟明显更低
  • 在连接设置中降低画质，可以换取更流畅的画面
  • 画面静止时界面上的延迟数值会自然增大，这反映的是「当前画面的新鲜度」， 不代表网络变慢；开始操作后会立即回落

忘记被控端密码

在被控设备的「协助」页，点击临时验证码右侧的刷新图标可重新生成。 如需固定不变的密码，可在「设置 → 安全 → 永久密码」中设置。

如何注销账号

手机端打开「我的 → 注销账号」，电脑端打开左下角「账号 → 注销账号」，输入密码确认。 注销会永久删除账号、云端设备列表与全部登录状态，且不可撤销。

关于安全

我们倾向于如实说明能力边界：

  • App 与服务器之间的通信（含登录、画面、控制指令）经 HTTPS / WSS 加密传输
  • 跨网络连接需经服务器中转，此时服务器在技术上可以访问画面内容。 目前尚未实现端到端加密，我们不读取、不留存这些内容
  • 对画面机密性有严格要求的场景，建议使用局域网直连， 此时数据不经过我们的服务器
  • 被控端必须主动开启共享并设置密码，他人无法在你不知情的情况下连入
