远程开机 · 2.3.0 起两个开关就能用

出门在外，也能一键开机家里的电脑。

家里一台常开的安卓手机或 Mac 作为开机助手，收到请求后在家庭局域网唤醒插网线的 Windows 电脑。电脑和手机登录同一账号即可，无需扫码配对，也不用在路由器开放公网端口。

01 / 家中助手
打开「开机助手」在留在家里的安卓手机或 Mac 上登录，开启「作为家中开机助手」，保持供电联网。
02 / Windows 电脑
打开「允许远程开机」网线连接路由器，在电脑上开启开关；有线网卡和家中助手自动识别。主板 BIOS 需开启网络唤醒。
03 / 外出时
点橙色「开机」在设备列表中点关机电脑的「开机」按钮；助手离线时会自动改用其他在线助手。

远程开机配套服务已部署。实际唤醒仍需电脑硬件支持，并完成家中助手配置；隔夜稳定性请按说明实测。

“已发出开机信号”只表示助手完成了广播，电脑启动并运行随控后才显示在线。当前 App Store 版本尚不包含远程开机。

下载前，你可能想了解

以后可以在应用里更新吗？

从 2.2.1 开始，应用运行时会自动检查新版，也可进入「设置 → 关于 → 检查更新」。Windows、Android、Mac 可以下载并校验安装包，再按系统提示完成安装。旧版请先从官网手动安装一次。Mac 仍需拖入应用程序替换；iPhone 通过 App Store 更新，商店尚未发布的版本不会被当作更新。应用关闭时不会收到更新推送。

哪些设备可以被远程操作？

Android 与 macOS 可作为被控端。Windows 当前提供控制端与远程开机配置，尚不支持共享 Windows 桌面给别人操作。iPhone/iPad 可作控制端，也可分享屏幕，但不能接收远程触控。

iPhone 可以像安卓一样下载文件安装吗？

官网的苹果手机按钮会前往 App Store。普通 IPA 文件不能像 APK 一样在任意 iPhone 上直接安装。

安装后需要开启哪些权限？

Mac 被控需要屏幕录制与辅助功能权限；Android 屏幕共享和远程操作按应用提示授权。作为开机助手时只需网络、通知与后台运行，不要求录屏或无障碍；Mac 助手不需要额外权限。

远程开机为什么需要实测？

不同主板、网卡、Windows 电源状态及安卓后台策略存在差异。先测试睡眠与刚关机，再测试蜂窝网络、隔夜、24 小时和 48 小时。失败时先看设备页里家中助手是否在线，再检查 BIOS、网卡的网络唤醒设置和 Windows「快速启动」。

我的系统版本能安装吗？

Mac 新版要求 macOS 12 或更高版本；Windows 支持 Windows 10/11 x64；Android 要求 7.0 或更高版本；App Store 当前版本支持 iOS/iPadOS 13 或更高版本，之后的新版需要 iOS/iPadOS 15。请下载与你设备相符的安装包。
