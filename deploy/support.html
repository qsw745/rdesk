快速开始

RDesk 需要两台设备：一台作为被控端（被查看和操作的设备）， 另一台作为主控端（发起连接的设备）。

  1. 在被控设备上安装并打开 RDesk，进入「远程连接」页， 记下页面下方显示的「本机设备 ID」与验证码
  2. 在主控设备上打开 RDesk，进入「远程连接」页
  3. 在「设备代码」填入被控设备的 ID，在「验证码」填入其密码
  4. 点击「密码连接」即可看到远程画面

常见问题

提示「未找到在线设备」

说明被控端当前不在线。请检查：

  • 被控设备上的 RDesk 是否正在运行（不能只是装了但没打开）
  • 被控设备是否联网
  • 设备 ID 是否输入正确（9 位数字）

连接成功但画面是黑的（macOS 被控端）

macOS 需要手动授予屏幕录制权限：

打开「系统设置 → 隐私与安全性 → 屏幕录制」，找到 RDesk 并打开开关。 授权后需要重新启动 RDesk 才会生效。

如果还需要用鼠标键盘操作对方电脑，同一位置的「辅助功能」也要一并授予。

iOS 设备能被别人看到，但对方操作不了

这是 iOS 系统的限制，不是故障。iOS 上的 RDesk 可以共享屏幕画面， 但系统不允许第三方 App 接收远程触控指令。

如果需要完整的远程操控，请把 Windows 或 macOS 设备作为被控端。

画面卡顿或延迟高

  • 优先使用局域网直连：两台设备在同一网络时， 在被控端「远程连接」页找到直连地址，主控端直接填该地址， 数据不经过服务器，延迟明显更低
  • 在连接设置中降低画质，可以换取更流畅的画面
  • 画面静止时界面上的延迟数值会自然增大，这反映的是「当前画面的新鲜度」， 不代表网络变慢；开始操作后会立即回落

忘记被控端密码

在被控设备的「远程连接」页，点击验证码右侧的刷新图标可重新生成临时密码。 如需固定不变的密码，可在「我的 → 无人值守设置」中设置。

如何注销账号

打开「我的 → 安全中心 → 注销账号」，输入密码确认即可。 注销会永久删除账号、云端设备列表与全部登录状态，且不可撤销。

关于安全

我们倾向于如实说明能力边界：

  • App 与服务器之间的通信（含登录、画面、控制指令）经 HTTPS / WSS 加密传输
  • 跨网络连接需经服务器中转，此时服务器在技术上可以访问画面内容。 目前尚未实现端到端加密，我们不读取、不留存这些内容
  • 对画面机密性有严格要求的场景，建议使用局域网直连， 此时数据不经过我们的服务器
  • 被控端必须主动开启共享并设置密码，他人无法在你不知情的情况下连入
